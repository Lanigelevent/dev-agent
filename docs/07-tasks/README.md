## 状态口径

| 术语 | 含义 |
|---|---|
| 待批 | 提案已写、总监未裁决（如 D-049 分层套件） |
| 待资源 | 等总监提供端点/镜像/语料等外部资源（如模型轴扩样） |
| 留观 | 不主动处置、按触发条件再看（多为宿主侧坑） |
| 已执行 | 该轮已完成并回填 docs/ROADMAP-HISTORY.md §5 与轮报（只增不改的完成记录）；当前待办只保留在 next-round.md |

## 类内约定

- 开局先读 next-round.md 并跑 `round-gate.py open`；收官回填第 N 条为新轮开局项。
- 未完成项不另设派生视图——next-round.md 是唯一待办源；已完成历史进 ROADMAP-HISTORY 与轮报，不建独立归档副本。
