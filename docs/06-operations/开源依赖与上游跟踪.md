# 开源依赖与上游跟踪

> **创建日期**：2026-11-25 ｜ **当前状态**：维护中 ｜ **所有者**：开发者 + 迭代官
> **权威范围**：项目直接引用或直接调用的开源项目、所提供能力、使用范围、上游仓库/发布页、版本核对与跟踪要点
> **不是权威**：依赖声明（`pyproject.toml`）、解析锁定版本（`uv.lock` / `requirements-lock.txt`）、实际安装版本（`.venv`）、许可证判定（`licenses.json` 与 `license-check.py`）
> **复核期限**：2026-12-31（随依赖刷新轮与 Dependabot 周报）｜ **上次复核**：2026-11-25

## 使用规则

- 版本快照以 2026-11-25 的 `.venv` / `uv.lock` 为准；表中版本用于上游导航，不替代现场取数。
- 直接依赖的增删只改 `pyproject.toml`，随后运行 `uv lock`、`uv sync --extra dev`、`uv export --extra dev`，并更新本表。
- Dependabot 每周检查 pip 与 GitHub Actions；依赖刷新轮每约 10 轮逐包 dry-run，并重测三引擎矩阵。
- 上游发布页是“获取最新动态”的唯一入口；许可证边界仍以 `license-check.py` 为准。
