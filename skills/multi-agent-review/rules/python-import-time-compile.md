# 规则：导入期/编译期生效的语义不只在调用期

**适用**：Python 正则模式串、装饰器参数、类属性默认值、模块级常量、`re.compile`
调用点、`__init__` 默认值等**导入或编译期才定型**的代码。

**判据**：改动模式串/编译期常量时，语义变化发生在导入（编译）时刻，而非
调用时刻。评审必须推演"模块被 import 的那一刻会发生什么"，不能只追踪
运行时调用链。

**反例形态**：修复把正则改为"到导入时才编译"，diff 里看调用点全部正确，
但模块一导入就按新语义编译——旧行为残留只出现在 import 顺序敏感的
场景，单看调用期 diff 完全发现不了。

**评审动作**：凡 diff 触及模块级语句、`re.compile`、装饰器参数、类体
赋值，问一句"这在导入期会执行成什么样？"——需要时要求给出导入期推演。

出处：SWE-bench 实例 astropy__astropy-14365（round-19 复盘：模型侧三处
修复都没覆盖"正则到导入时才编译"这一层）。
