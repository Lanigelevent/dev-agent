# 案例 542cf8d43709：PR-Agent GitHub Action 模式：最低成本评审闭环

- 类别：交付面 | 类型：优秀案例 | 状态：verified

## 详细摘抄

PR-Agent（MIT，社区接管）验证 Action 模式（.github/workflows 触发 pull_request+issue_comment，permissions: pull-requests: write）为最低成本闭环；行内评论走 REST POST /pulls/{n}/comments（commit_id+path+line，token 写权限）。我们的 pr-kit 行内评论包只差海报脚本。

## 教训与对策

不自建 GitHub App；Action 模式 + REST 行内评论即可达行业标准交付形态。
