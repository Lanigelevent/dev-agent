# 项目多视角审查报告（2026-11-05，基于 v1.85.0 / a623728 线）

> 审查人：代理（round-77..84 全程深度参与者，第一手观察 + 证据采集）；
> 性质：总监委托的全面审查，非轮报；改进项经总监确认后进 next-round。

**审查基线**：75 脚本（治理壳 19,432 行）+ agent 层 5,674 行 + 引擎层

## 一、各维度评估

### 1. 架构设计 —— A-

强项：分层依赖宪法可机械执行（license-check 三档判定）；写权限五道
闸 + 修复/审核分立 + 永不自审自批；技能化 CLI + 单 JSON stdout 契约。
主要问题：agent/code-task.py God Script（2,388 行七个关注点）；治理壳
（runner.py 1,087 行）与实际工作方式脱节——r77..84 评测操作走会话内联
一行式，产物落 gitignored _work，复现靠报告描述。

### 2. 代码质量 —— A-

强项：注解与 docstring 纪律（机械检查）；TODO 全仓 1 处；反向验证是
文化（r79/r81/r83 三次当轮抓出真实缺陷）。主要问题：超长函数；
worktree 准备/种子逻辑在一次性脚本中复制 3 次未产品化。

### 3. 可维护性 —— B+

强项：决策账 D-001..D-048；真值源制度 + 双机械门禁；PENDING 指针。
主要问题：append-only 文档膨胀（BASELINE 1,968 行 / ROADMAP 42 节 /
next-round 983 行）；版本七处与计数多处靠人工+事后门禁同步（每轮
1-2 循环损耗）。

### 4. 性能 —— B+（非核心目标）

套件波动负载主导（r80 归因）；风险：规模每轮 +2~5 项（527→545），
约 20 轮后常态逼近 600s 护栏——需提前决策分层套件。

### 5. 安全性 —— A-

强项：secret-scan、SSRF 白名单、路径越界检查、脱敏、凭据纪律
（r77..84 三个 key 零落盘实测）。风险：setup_cmds shell=True 的信任
边界未文档化；key 曾在对话明文（已轮换，建议轮换动作入收官检查单）。

### 6. 可测试性 —— A-

强项：545 契约全离线、双跑纪律、反向验证文化。主要问题：test_scripts.py
4,070 行巨石；覆盖率数值无常态出数；真实端点行为只能实跑暴露（本轮
三坑皆出于此层）。

### 7. 依赖与配置管理 —— A

三档许可证机械执行、零依赖治理壳、uv+清华镜像、fingerprint 覆盖。
缺口：依赖刷新无定期机制（r47 后未盘点）。

### 8. 文档完善度 —— B+

数量与纪律一流，但「写」有纪律、「读」体验恶化：README 状态行 3,000+
字符；PROGRESS 巨石单元格；沿革与现行未分卷。

### 9. 测试覆盖情况 —— A-

75 脚本 100% 被测试覆盖（Q4 机械保证）；契约分层清晰；失败归因与
integrity 闸完整。盲区：真实 LLM 端点层、host 端到端小 n。

1. P0-2：评测运行面收编为 eval-harness/gate-run.py（prepare/run/judge/
   report 单命令；judge 委托 live-sample，不复制判分逻辑）。
2. P1-3：拆分 code-task.py（materials/loop/phases/review_gate/protocol，
   545 契约做安全网，行为字节级不变）。
3. P1-4：文档分卷（BASELINE 沿革卷+现行卷；PROGRESS 列表化；README
   状态行收敛）。
4. P1-5：bump-version.py 单命令生成七处版本+计数真值。
5. P1-6：依赖刷新钉进轮次纪律（每 10 轮盘点）。
6. P2-7：分层套件提案（smoke/full，D-049）。
7. P2-9：评测信任边界条款入 DEVELOPMENT。

## 四、总体结论

工程纪律罕见严格的个人规模项目：治理先行真实落地（五道闸/分权/双跑/
发布闸/台账全部机械执行且 r77-84 逐一实战验证）；评测诚实度突出
（部分口径单列、blocked 逐仓、n 值不外推）。短板在「会话驱动的工作
方式沉淀不足」与「append-only 文档熵增」，均有低成本修正路径。当前
最有价值一步 = 运行面产品化（P0-2），同时缓解可维护性、复现性与
扩样效率。
