## 检索结论（2026-11-07，宿主九路检索已执行；结论回填）

### P0-1 resolved 口径（证据面）
- **发现**：官方 [sb-cli](https://github.com/SWE-bench/sb-cli) 支持**远端评测**
  （`sb-cli submit swe-bench_verified predictions.jsonl ...` + `get-report`），
  无需本地 120GB docker（官方 FAQ 亦给出本地省盘选项：跑后即删镜像）。
  行业第一梯队 resolved 71-97%（OpenHands 71.8%、Opus 4.5 79.2%）。
- **吸收**：predictions JSONL（instance_id + model_patch）格式与我们
  live-sample 台账字段天然对齐；在 live-sample 增 `--export-sbcli` 导出
  通路，f2p_passed 样本送官方远端评测出 resolved 口径，n 值如实标注。
- **来源**：swebench.com/sb-cli；SWE-bench FAQ（省盘三法：跑后删镜像/
  cache_level/降 --workers）。

### P0-2 中立评审基准
- **发现**：[SWRBench](https://github.com/ZZR0/SWRench)（arXiv:2509.01494，
  ~1000 真实 PR + ground truth 评分 harness）；[Code Review Bench](
  https://github.com/withmartian/code-review-benchmark)（开源可跑，含
  methodology/full.md）；MacroscopeBench（12k 真实 bug/1500 仓/14 语言，
  厂商自建）；研究界正集中批评厂商自评基准。
- **吸收**：precision 护栏补中立交叉验证臂——SWRBench 数据接入
  reviewbench-eval.py 适配面（自建 ReviewBench 保持，双轨出数）。
- **来源**：arXiv:2509.01494；withmartian/code-review-benchmark。

### P0-3 GitHub 集成闭环
- **发现**：[PR-Agent](https://github.com/The-PR-Agent/pr-agent)（MIT，社区
  接管）证明 **GitHub Action 模式**是最低成本闭环：.github/workflows 触发
  pull_request + issue_comment（slash 命令），permissions: pull-requests:
  write；行内评论走 REST `POST /repos/{o}/{r}/pulls/{n}/comments`
  （commit_id + path + line，需 push 权限/token 写 PR 权限）。
- **吸收**：pr-kit.py 已产行内评论包（file/line/severity/message）——缺的
  只是海报脚本（token 走环境变量，pr-publish.py 同款纪律）+ 一个
  workflow 文件。不自建 App，Action 模式即可。
- **来源**：qodo-merge-docs；docs.github.com/rest/pulls/comments。

### P1 上下文面
- **发现**：[Aider repo map](https://aider.chat/2023/10/22/repomap.html)
  = tree-sitter 符号图 + personalized PageRank + token 预算截断；业界批评：
  静态结构排名无调用路径/数据流，弱连接仓退化。我们的「关键词候选 +
  定义点取窗」路线与其实质同构；D-031 已实测 graph rank 无增益（Top-8）。
- **吸收**：暂不引入 embedding（零依赖约束 + 实测无增益先例）；保留
  观测项：若 verified 扩样在大仓（>2k 文件）持续受阻再评估 sqlite-vec。

### P1 Semgrep 进主流程
- **发现**：semgrep --json + Registry 规则包 + SARIF 输出（GitHub Security
  tab）是行业标准接线；DefectDojo 等按 JSON 摄取。
- **吸收**：engines/semgrep_adapter.py（LGPL subprocess 已合规）作为评审
  第 4 引擎维度进 dispatch-plan 白名单，前缀 semgrep:<id>，与 ruff/libcst/
  ast-grep 同链分诊。
- **来源**：docs.semgrep.dev/deployment/oss-deployment。

### P2 测试生成证据面
- **发现**：[TestGenEval](https://github.com/facebookresearch/testgeneval)
  （1210 Python 文件对，compile@k/pass@k，Meta）+ TestGen-LLM 三重验收
  （build/pass/coverage 提升）。
- **吸收**：testgen.py 的 verify 闸已实现 TestGen-LLM 式过滤；TestGenEval
  lite 作为后续证据面（非当前优先）。
